# UI Design & Button Hierarchy Rules

1. **Only ONE Primary Button Per Page**:
   - Each page, view, drawer, or modal header MUST have strictly **ONLY ONE PRIMARY BUTTON** (the single main visual action button, e.g. `bg-brand-600` or `bg-slate-900` with high contrast text).
   - All other header buttons, secondary actions, export buttons, filter buttons, draft buttons, back buttons, and auxiliary actions MUST be styled as **Secondary Buttons** (`bg-slate-100 dark:bg-slate-800 border border-slate-200 dark:border-slate-700 text-slate-700 dark:text-slate-300 hover:bg-slate-200` or soft tint `bg-brand-50 text-brand-700 border border-brand-200`).
